COMPONENT 1: DENSITY MAP MODULE
================================
Purpose: Build and maintain occupancy probability grid with uncertainty

Responsibilities:
- Convert sensor data (LiDAR scans) to occupancy grid
- Track confidence/uncertainty in each cell
- Calculate entropy at each location
- Update based on new observations
- Integrate EKF covariance for positional uncertainty

Key Classes:
class DensityMap:
    - __init__(width, height, resolution, origin)
    - update_from_scan(scan_msg, robot_pose, confidence)
    - update_from_costmap(costmap_msg)
    - get_entropy_map() -> numpy array
    - get_cell_probability(x, y) -> float [0.0, 1.0]
    - get_cell_entropy(x, y) -> float [0.0, 1.0]
    - get_high_entropy_regions(threshold) -> list of regions
    - to_occupancy_grid() -> OccupancyGrid (for visualization)
    - decay_old_observations(decay_rate)

Critical Parameters:
    - grid_width: 100m (covers 50m+ in all directions)
    - grid_height: 100m
    - resolution: 0.2m (manageable on Jetson: 500x500 = 250k cells)
    - max_range: 12.0m (LiDAR effective range)
    - confidence_initial: 0.0 (unknown)
    - confidence_decay_rate: 0.95 per second (observations fade)

Memory Budget:
    - Grid size: 500 x 500 x float32 = 1MB
    - Confidence grid: 1MB
    - Entropy grid: 1MB
    - Total: ~3MB (well within constraints)


COMPONENT 2: ENTROPY CALCULATOR
================================
Purpose: Compute information-theoretic measures

Responsibilities:
- Calculate Shannon entropy from occupancy probabilities
- Compute information gain from potential observations
- Identify high-entropy (unexplored) regions
- Rank locations by information value
- Account for sensor field-of-view constraints

Key Classes:
class EntropyCalculator:
    - entropy(probability) -> float
    - information_gain(density_map, location, sensor_fov) -> float
    - find_high_entropy_cells(density_map, threshold) -> list
    - rank_by_entropy(density_map, candidates) -> sorted list
    - compute_expected_info_gain(trajectory, density_map) -> float

Mathematical Formulas:
    Entropy: H(p) = -p*log2(p) - (1-p)*log2(1-p)
    
    Information Gain:
    IG = Σ H(p_before) - H(p_after)
    where p_after = observed state (0 or 1 with high confidence)

    Expected Info Gain from trajectory:
    E[IG] = Σ H(p_cell) for all cells in sensor FOV

COMPONENT 4: FRONTIER EXPLORER
===============================
Purpose: Boundary-based exploration

Algorithm:
1. Find frontier cells (boundary between free and unknown)
2. Cluster frontier cells using connected components
3. Select nearest cluster or largest cluster
4. Return centroid as goal

Advantages:
- Fastest computation (O(n) where n = grid size)
- Proven algorithm (standard in ROS SLAM)
- Very low CPU load (5-10%)

Implementation Notes:
- Use scipy.ndimage for connected component labeling
- Frontier = UNKNOWN cell adjacent to FREE cell
- Prefer frontiers with width > min_frontier_size
- Filter by distance (max 20m from robot)

Expected Performance:
- Computation time: 10-20ms
- CPU load: 5-10%
- Good coverage in open areas
- May miss small open spaces


COMPONENT 5: INFORMATION GAIN EXPLORER
=======================================
Purpose: Entropy-driven exploration

Algorithm:
1. Sample candidate locations in circular rings around robot
2. For each candidate, simulate sensor observation
3. Compute expected information gain
4. Select location with highest information gain
5. Apply distance penalty to prefer closer goals

Advantages:
- Theoretically optimal for information maximization
- Leverages full density map
- Accounts for uncertainty explicitly

Implementation Notes:
- Generate candidates at distances: [5, 10, 15] meters
- Generate candidates at angles: 0-360° with 22.5° spacing (16 samples)
- Total candidates: 3 distances × 16 angles = 48 candidates
- Ray-trace from candidate to compute observable cells
- Weight information gain by confidence
- Penalize distance: discount_factor = exp(-0.1 * distance)

Expected Performance:
- Computation time: 50-100ms
- CPU load: 15-25%
- Better balance of exploration vs efficiency
- Higher information gain than frontier


COMPONENT 6: NEXT-BEST-VIEW EXPLORER
=====================================
Purpose: Sophisticated viewpoint selection

Algorithm:
1. Generate candidate viewpoints (more expensive)
2. For each candidate:
   a. Simulate ray-tracing from that viewpoint
   b. Account for occlusions (terrain/obstacles block view)
   c. Compute cells that would become observable
   d. Weight by current entropy of those cells
3. Select viewpoint with maximum information gain
4. Apply distance penalty

Advantages:
- Most sophisticated algorithm
- Accounts for occlusions
- Can find optimal paths in complex environments

Disadvantages:
- Highest computational cost (200-400ms per cycle)
- May exceed Jetson Nano budget if not optimized
- Requires careful implementation

Implementation Notes:
- Generate candidates at finer resolution: distances [3, 6, 9, 12, 15]
- Generate angles: 32 directions (11.25° spacing)
- Total candidates: 5 × 32 = 160 candidates
- For each: ray-trace to compute visible cells
- Use pre-computed ray-traces to speed up
- Cache results if same viewpoint queried
- Update cache every 5 seconds

Expected Performance:
- Computation time: 150-300ms (may approach budget limit)
- CPU load: 30-50%
- Best information gain
- Slowest response time

import numpy as np
from nav_msgs.msg import OccupancyGrid
from geometry_msgs.msg import Pose, Point, Quaternion
from sensor_msgs.msg import LaserScan
import math

class DensityMap:
    """
    Represents robot environment as occupancy probability grid.
    
    Grid cells contain:
    - occupancy: probability of being occupied [0.0, 1.0]
    - confidence: certainty of the classification [0.0, 1.0]
    - entropy: information value at each cell
    """
    
    def __init__(self, width: float, height: float, resolution: float, 
                 origin_x: float = 0.0, origin_y: float = 0.0):
        """
        Initialize density map.
        
        Args:
            width: Grid width in meters
            height: Grid height in meters
            resolution: Cell resolution in meters
            origin_x: World x-coordinate of grid origin
            origin_y: World y-coordinate of grid origin
        """
        self.width_m = width
        self.height_m = height
        self.resolution = resolution
        self.origin_x = origin_x
        self.origin_y = origin_y
        
        # Grid dimensions in cells
        self.grid_width = int(width / resolution)
        self.grid_height = int(height / resolution)
        
        # Initialize grids (center robot at origin)
        self.occupancy = np.full((self.grid_height, self.grid_width), 0.5)
        self.confidence = np.zeros((self.grid_height, self.grid_width))
        self.entropy = np.full((self.grid_height, self.grid_width), 1.0)
        
        # Track observation count for averaging
        self.observation_count = np.zeros((self.grid_height, self.grid_width))
        self.last_update_time = {}  # For decay calculations
        
    def world_to_grid(self, world_x: float, world_y: float) -> tuple:
        """Convert world coordinates to grid indices"""
        grid_x = int((world_x - self.origin_x) / self.resolution + 
                     self.grid_width / 2)
        grid_y = int((world_y - self.origin_y) / self.resolution + 
                     self.grid_height / 2)
        return grid_x, grid_y
    
    def grid_to_world(self, grid_x: int, grid_y: int) -> tuple:
        """Convert grid indices to world coordinates"""
        world_x = (grid_x - self.grid_width / 2) * self.resolution + self.origin_x
        world_y = (grid_y - self.grid_height / 2) * self.resolution + self.origin_y
        return world_x, world_y
    
    def is_valid(self, grid_x: int, grid_y: int) -> bool:
        """Check if grid coordinates are valid"""
        return (0 <= grid_x < self.grid_width and 
                0 <= grid_y < self.grid_height)
    
    def update_from_scan(self, scan_msg: LaserScan, robot_x: float, 
                         robot_y: float, robot_theta: float, 
                         confidence: float = 0.9, timestamp = None):
        """
        Update density map from LiDAR scan using raycasting.
        
        Args:
            scan_msg: LaserScan message
            robot_x: Robot x position in world frame
            robot_y: Robot y position in world frame
            robot_theta: Robot orientation in world frame
            confidence: Confidence in this observation [0.0, 1.0]
            timestamp: Observation timestamp for decay calculation
        """
        # Get robot grid position
        robot_gx, robot_gy = self.world_to_grid(robot_x, robot_y)
        
        for i, range_val in enumerate(scan_msg.ranges):
            if scan_msg.range_min <= range_val <= scan_msg.range_max:
                # Calculate angle of this beam in world frame
                beam_angle = scan_msg.angle_min + i * scan_msg.angle_increment
                world_angle = robot_theta + beam_angle
                
                # Calculate hit point
                hit_x = robot_x + range_val * math.cos(world_angle)
                hit_y = robot_y + range_val * math.sin(world_angle)
                hit_gx, hit_gy = self.world_to_grid(hit_x, hit_y)
                
                # Raycast from robot to hit point
                self._raycast_mark_free(robot_gx, robot_gy, hit_gx, hit_gy, 
                                       confidence, timestamp)
                
                # Mark hit point as occupied
                if self.is_valid(hit_gx, hit_gy):
                    self._update_cell(hit_gx, hit_gy, occupancy=1.0, 
                                    confidence=confidence, timestamp=timestamp)
    
    def _raycast_mark_free(self, start_x: int, start_y: int, 
                          end_x: int, end_y: int, confidence: float, 
                          timestamp):
        """Raycast and mark all cells as free along the ray"""
        # Bresenham's line algorithm
        dx = abs(end_x - start_x)
        dy = abs(end_y - start_y)
        sx = 1 if end_x > start_x else -1
        sy = 1 if end_y > start_y else -1
        err = dx - dy
        
        x, y = start_x, start_y
        while True:
            if self.is_valid(x, y):
                self._update_cell(x, y, occupancy=0.0, confidence=confidence, 
                                timestamp=timestamp)
            
            if x == end_x and y == end_y:
                break
            
            e2 = 2 * err
            if e2 > -dy:
                err -= dy
                x += sx
            if e2 < dx:
                err += dx
                y += sy
    
    def _update_cell(self, grid_x: int, grid_y: int, occupancy: float, 
                    confidence: float, timestamp = None):
        """Update a single cell with Bayesian update"""
        if not self.is_valid(grid_x, grid_y):
            return
        
        # Current state
        current_prob = self.occupancy[grid_y, grid_x]
        current_conf = self.confidence[grid_y, grid_x]
        
        # Bayesian update: weighted average
        # New probability = (confidence * new_obs + current_conf * current) 
        #                   / (confidence + current_conf)
        total_conf = confidence + current_conf
        if total_conf > 0:
            self.occupancy[grid_y, grid_x] = (
                confidence * occupancy + current_conf * current_prob
            ) / total_conf
            self.confidence[grid_y, grid_x] = min(total_conf, 1.0)
        else:
            self.occupancy[grid_y, grid_x] = occupancy
            self.confidence[grid_y, grid_x] = confidence
        
        self.observation_count[grid_y, grid_x] += 1
        self.last_update_time[(grid_x, grid_y)] = timestamp
        
        # Update entropy
        self._update_cell_entropy(grid_x, grid_y)
    
    def _update_cell_entropy(self, grid_x: int, grid_y: int):
        """Recompute entropy for a cell"""
        p = self.occupancy[grid_y, grid_x]
        if 0 < p < 1:
            self.entropy[grid_y, grid_x] = -p * math.log2(p) - (1-p) * math.log2(1-p)
        else:
            self.entropy[grid_y, grid_x] = 0.0
    
    def decay_observations(self, current_time, half_life: float = 30.0):
        """
        Decay old observations to reduce stale information.
        
        Args:
            current_time: Current timestamp
            half_life: Time (seconds) for confidence to drop to 50%
        """
        decay_rate = 0.5 ** (1.0 / half_life)  # Per second
        
        for grid_y in range(self.grid_height):
            for grid_x in range(self.grid_width):
                last_time = self.last_update_time.get((grid_x, grid_y))
                if last_time is not None:
                    time_delta = (current_time - last_time).total_seconds()
                    decay_factor = decay_rate ** time_delta
                    
                    # Decay confidence back toward 0.5 (unknown)
                    self.confidence[grid_y, grid_x] *= decay_factor
                    self.occupancy[grid_y, grid_x] = (
                        self.occupancy[grid_y, grid_x] * self.confidence[grid_y, grid_x] +
                        0.5 * (1 - self.confidence[grid_y, grid_x])
                    )
                    self._update_cell_entropy(grid_x, grid_y)
    
    def to_occupancy_grid(self, frame_id: str = 'map', 
                         timestamp = None) -> OccupancyGrid:
        """Convert internal representation to ROS OccupancyGrid message"""
        msg = OccupancyGrid()
        msg.header.frame_id = frame_id
        msg.header.stamp = timestamp if timestamp else self._get_clock_time()
        
        msg.info.resolution = self.resolution
        msg.info.width = self.grid_width
        msg.info.height = self.grid_height
        msg.info.origin = Pose(
            position=Point(x=-self.grid_width/2*self.resolution, 
                          y=-self.grid_height/2*self.resolution, z=0),
            orientation=Quaternion(w=1.0)
        )
        
        # Convert to ROS convention: 0=free, 100=occupied, -1=unknown
        msg.data = [int(100 * p) for p in self.occupancy.flatten()]
        
        return msg
    
    def get_high_entropy_cells(self, threshold: float = 0.8) -> list:
        """Get list of cells with entropy above threshold"""
        cells = []
        for grid_y in range(self.grid_height):
            for grid_x in range(self.grid_width):
                if self.entropy[grid_y, grid_x] >= threshold:
                    world_x, world_y = self.grid_to_world(grid_x, grid_y)
                    cells.append((world_x, world_y, self.entropy[grid_y, grid_x]))
        return cells

import numpy as np
import math
from typing import List, Tuple

class EntropyCalculator:
    """Calculate information-theoretic measures for exploration"""
    
    @staticmethod
    def entropy(probability: float) -> float:
        """
        Calculate Shannon entropy for a probability.
        
        H(p) = -p*log2(p) - (1-p)*log2(1-p)
        Returns 1.0 for p=0.5 (maximum uncertainty)
        Returns 0.0 for p=0 or p=1 (certainty)
        """
        if probability <= 0 or probability >= 1:
            return 0.0
        return -probability * math.log2(probability) - (1 - probability) * math.log2(1 - probability)
    
    @staticmethod
    def information_gain(prob_before: float, prob_after: float) -> float:
        """
        Calculate information gain from observation.
        
        IG = H(before) - H(after)
        """
        return EntropyCalculator.entropy(prob_before) - \
               EntropyCalculator.entropy(prob_after)
    
    @staticmethod
    def get_cells_in_circle(center_x: float, center_y: float, 
                            radius: float, density_map) -> List[Tuple[int, int]]:
        """
        Get all grid cells within a circular region.
        
        Args:
            center_x, center_y: Center in world coordinates
            radius: Radius in meters
            density_map: DensityMap object
            
        Returns:
            List of (grid_x, grid_y) tuples
        """
        cells = []
        grid_cx, grid_cy = density_map.world_to_grid(center_x, center_y)
        grid_radius = int(radius / density_map.resolution)
        
        for dy in range(-grid_radius, grid_radius + 1):
            for dx in range(-grid_radius, grid_radius + 1):
                dist_sq = dx*dx + dy*dy
                if dist_sq <= grid_radius * grid_radius:
                    grid_x = grid_cx + dx
                    grid_y = grid_cy + dy
                    if density_map.is_valid(grid_x, grid_y):
                        cells.append((grid_x, grid_y))
        
        return cells
    
    @staticmethod
    def compute_info_gain_at_location(location_x: float, location_y: float,
                                      robot_sensor_range: float, 
                                      density_map) -> float:
        """
        Compute expected information gain if robot observes from location.
        
        Args:
            location_x, location_y: Potential observation location (world coords)
            robot_sensor_range: Maximum sensor range (e.g., 12m for LiDAR)
            density_map: Current density map
            
        Returns:
            Total information gain (bits)
        """
        # Get all cells within sensor range
        cells = EntropyCalculator.get_cells_in_circle(
            location_x, location_y, robot_sensor_range, density_map
        )
        
        # Sum entropy (each cell observed would go from uncertain to certain)
        total_info_gain = 0.0
        for grid_x, grid_y in cells:
            prob = density_map.occupancy[grid_y, grid_x]
            confidence = density_map.confidence[grid_y, grid_x]
            
            # Only count weakly-observed cells
            if confidence < 0.8:
                # Assume observation will make us certain (confidence → 1.0)
                info_gain = EntropyCalculator.information_gain(prob, 1.0) if prob > 0.5 \
                           else EntropyCalculator.information_gain(prob, 0.0)
                total_info_gain += info_gain
        
        return total_info_gain

from abc import ABC, abstractmethod
from geometry_msgs.msg import Pose, Point, Quaternion
from typing import Optional

class BaseExplorer(ABC):
    """
    Abstract base class for exploration algorithms.
    
    All exploration strategies inherit from this class and implement
    the compute_goal() method.
    """
    
    def __init__(self, node, params: dict):
        """
        Initialize explorer.
        
        Args:
            node: ROS2 node (for logging and utilities)
            params: Configuration parameters from YAML
        """
        self.node = node
        self.params = params
        self.logger = node.get_logger()
    
    @abstractmethod
    def compute_goal(self, density_map, robot_state, costmap) -> Optional[Pose]:
        """
        Compute next exploration goal.
        
        Args:
            density_map: DensityMap object
            robot_state: Dict with keys: 'position' (x, y), 'orientation', 'velocity'
            costmap: Nav2 OccupancyGrid costmap
        
        Returns:
            Pose representing goal, or None if no valid goal found
        """
        raise NotImplementedError
    
    def name(self) -> str:
        """Return algorithm name"""
        raise NotImplementedError
    
    def validate_goal(self, goal: Pose, costmap) -> bool:
        """
        Check if goal is valid (in free space).
        
        Args:
            goal: Pose to validate
            costmap: OccupancyGrid
            
        Returns:
            True if goal is in free space, False otherwise
        """
        grid_x = int((goal.position.x - costmap.info.origin.position.x) / 
                    costmap.info.resolution)
        grid_y = int((goal.position.y - costmap.info.origin.position.y) / 
                    costmap.info.resolution)
        
        if not (0 <= grid_x < costmap.info.width and 
                0 <= grid_y < costmap.info.height):
            return False
        
        cell_idx = grid_y * costmap.info.width + grid_x
        cost = costmap.data[cell_idx]
        
        # Cost < 50 = free space
        return cost < 50
    
    def create_pose(self, x: float, y: float) -> Pose:
        """Helper to create a Pose"""
        return Pose(
            position=Point(x=x, y=y, z=0.0),
            orientation=Quaternion(x=0.0, y=0.0, z=0.0, w=1.0)
        )
